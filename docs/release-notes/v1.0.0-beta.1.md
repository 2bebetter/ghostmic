GhostMic 让文字通过 macOS 系统声音说出来；配合 BlackHole，可以在其他应用中作为麦克风输入。

### 下载安装

需要 macOS 14.5 或更新版本。在下方 Assets 中下载对应文件，解压后将 GhostMic.app 拖到“应用程序”：

- Apple 芯片：`GhostMic-arm64.zip`（约 35 MiB）
- Intel 芯片：`GhostMic-x86_64.zip`（约 36 MiB）

应用已包含 Python 和播放组件，不需要另外安装 Python。语音在本机生成。希望将声音作为麦克风使用时，需要另外安装 BlackHole 2ch，并在 GhostMic 中选择它作为输出设备，在目标应用中选择它作为麦克风。

### 首次打开

这是免费提供的预览版，使用临时签名，尚未经过 Apple 开发者签名和公证，macOS 可能会阻止首次打开。确认安装包来自本项目且你信任它后，可尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”，按系统提示确认。如果系统提示应用已损坏或含有恶意软件，请勿强行打开。

Apple 芯片和 Intel 安装包均已在 Apple 芯片 Mac 上测试；Intel 版通过 Rosetta 测试，尚未在 Intel 真机上验证。欢迎反馈使用问题。

每个 ZIP 对应的 `.sha256` 文件可用于校验下载内容。源码安装方式、旧录音迁移和更多使用说明见仓库 README。
