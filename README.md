# GhostMic

让文字「说」进麦克风。

一个 macOS 上的本地小工具：输入文字，生成语音，播放到虚拟音频设备（BlackHole），
浏览器或 AI 工具就会把这段语音当成真实的麦克风输入。

适合做语音功能的测试 —— **不用自己开口**。

---

## 它解决什么问题

测试语音输入相关的功能时，一般得对着麦克风念稿子。麻烦、不可复现，
同一句话难以反复测。这个小工具把「说」这一步变成可保存、可重复的音频。

原来要手敲三条命令：

```bash
say -v Tingting -o voice.aiff "你好"
afconvert -f WAVE -d LEI16@16000 voice.aiff voice_16k.wav
# 再想办法把 wav 放给 BlackHole
```

现在是一个网页：输文字、点一下，音频生成 + 送进麦克风。历史音频自动列表管理，
不用再手动清理残留。

## 开始使用

### 1. 装虚拟声卡（只需一次）

下载安装 [BlackHole](https://existential.audio/blackhole/)（免费，2ch 版本即可）。
装完在「系统设置 → 声音」里能看到 `BlackHole 2ch` 就成功了。

### 2. 装 Python 依赖（只需一次）

```bash
python3 -m pip install --user sounddevice numpy
```

> 只用 macOS 自带的 `say` 和 `afconvert` 做合成，不需要额外的语音库。

### 3. 启动

**双击 `启动工具.command`**，浏览器会自动打开 <http://127.0.0.1:8787/>。

如果想在终端里启动：

```bash
python3 server.py
```

### 4. 在浏览器 / AI 工具里接上

1. 麦克风设备选 **BlackHole 2ch**
2. 点它的听筒（录音）按钮，第一次会问是否允许使用麦克风 —— 点允许
3. 回到 GhostMic，点「生成并送去麦克风」

声音就进去了。

## 关闭

点页面右上角 **「退出工具」**，确认后服务停止、端口释放。
音频文件不会删，下次启动还在。

关掉那个终端窗口也一样能关。

---

## 音频存在哪

和程序同级的 `audio/` 目录里，标准的 16kHz 单声道 wav。
文件可以直接拖进任何工具用，也可以手动删。

## 常见问题

**为什么放进去了我听不到声音？**

BlackHole 是虚拟声卡，本身不出声 —— 声音被"转走"了，不是被"播放"了。
想同时自己听到，需要在「音频 MIDI 设置」里建一个**多输出设备**
（勾上扬声器 + BlackHole），再把系统输出切到它。

**浏览器找不到 BlackHole 2ch？**

装完 BlackHole 需要重启浏览器；还不行就重启一次系统。
在「系统设置 → 声音 → 输入」里确认能看到它。

**换了一句话，生成的音频会覆盖吗？**

不会。每段音频带时间戳独立保存，同一句话可以生成很多次，互不影响。

**端口 8787 被占了怎么办？**

改 `server.py` 顶部的 `PORT` 即可。

## 技术说明

- 合成：macOS `say`（内置多种中文音色）→ `afconvert` 转 16kHz 单声道 wav
- 播放：Python `sounddevice`（PortAudio），可精确指定输出到哪个设备
- 服务：Python 标准库 `http.server`，只监听 `127.0.0.1`，外部访问不到
- 界面：单文件 HTML，无框架、无构建步骤

> 关于 `say`：它**不支持** `--data-format` 参数，硬加会报
> `Opening output file failed: fmt?`。格式转换要交给 `afconvert`。

## 环境要求

- macOS（依赖 `say`、`afconvert`，仅系统自带）
